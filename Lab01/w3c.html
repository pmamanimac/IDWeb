Qué es SVG?

  • Se utiliza para definir gráficos vectoriales
  • Define gráficos en formato XML
  • Cada elemento y atributo de los archivos SVG puede animarse
  • SVG se integra con otros estándares, como CSS, DOM, XSL y JavaScript

Ventajas

  • Las imágenes SVG se pueden crear y editar con cualquier editor de texto
  • Las imágenes SVG se pueden buscar, indexar, manipular mediante scripts y comprimir
  • Las imágenes SVG son escalables
  • Las imágenes SVG se pueden imprimir con alta calidad a cualquier resolución
  • SVG es un estándar abierto
  • Los archivos SVG son XML puro

Cómo funciona?

SVG cuenta con elementos y atributos para rectángulos, círculos, elipses, líneas, polígonos, curvas y más.

SVG también admite efectos de filtro y desenfoque, degradados, rotaciones, animaciones, interactividad con JavaScript y más.

Un documento SVG sencillo consta del elemento raíz svg(tag) y varios elementos de formas básicas que, en conjunto, conforman un gráfico.
